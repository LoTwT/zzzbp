# 单局常规 BP

本文维护第一版已确认的 BP 范围、禁选规则和交互方式，尚未确认的事项列于文末。

## 已确认范围

第一版只做单局常规 BP，不实现传奇对决，也不加入场地鸣徽。房间角色见[房间角色](room-roles.md)。

## 操作标记

标记由阵营、动作和本方累计序号组成：

- 阵营使用 `A` 和 `B`，分别表示 BP 先手方与后手方。
- 动作使用 `B` 表示禁用，使用 `P` 表示选用。
- 双方分别累计禁用与选用序号，跨轮次连续编号。禁用编号为 1 至 4，选用编号为 1 至 9。

例如，`AB1` 表示 A 方第 1 个禁用位，`BP7` 表示 B 方第 7 个选用位。

## 已确认的操作顺序

| 阶段 | 操作顺序 |
|---|---|
| 第一轮禁用 | `AB1` → `BB1` → `AB2` → `BB2` |
| 第一轮选用 | `AP1` → `BP1` → `BP2` → `AP2` → `AP3` → `BP3` → `BP4` → `AP4` → `AP5` → `BP5` → `BP6` → `AP6` |
| 第二轮禁用 | `BB3` → `AB3` → `BB4` → `AB4` |
| 第二轮选用 | `BP7` → `AP7` → `AP8` → `BP8` → `BP9` → `AP9` |

每方共 4 个禁用位和 9 个选用位，全程共 26 个位置。上述顺序参考[第四届拓金杯赛事手册的常规 BP 图](https://docs.qq.com/sheet/DZFVMWnhycGRrb0hv?tab=cyvwp8)，并经用户确认采用。

每个操作位置单独确认，连续属于同一方的位置也逐个提交。

## 代理人可用性

双方共用一个互斥的代理人池，采用以下已确认的规则：

1. 禁用对双方生效：任意一方禁用某名代理人后，双方都不能再禁用或选用该代理人。
2. 双方选用互斥：任意一方选定某名代理人后，另一方不能再选用；同一方也不能重复选用。
3. 已选代理人不再允许禁用：第二轮只能禁用仍未被选择、且未被禁用的代理人。

例如，`AP1` 选定星见雅后，B 方后续不能选用她，`BB3` 也不能再禁用她。

## 提交方式

1. BP 进行中，当前操作方点击代理人进行预选，确认前可以更换预选对象。
2. 禁用时点击「确认禁用」，选用时点击「确认选用」，提交当前操作位置的选择。
3. 每个位置单独确认，提交成功后按既定流程推进。连续选用两名代理人时，也需要逐个确认。

例如，`BP1` 提交后仍由 B 方操作 `BP2`；`BP2` 提交后，再由 A 方操作 `AP2`。

每次轮到一个操作位置，只接受一次有效提交。重复或过期提交不会推进到下一步，各页面同步显示已接受提交后的 BP 状态。

预选的展示方式与可见范围见[房间布局：预选展示](room-layout.md#预选展示)，确认按钮的位置、可见性与可用状态见[禁选确认按钮](room-layout.md#禁选确认按钮)。

最后一个位置 `AP9` 提交后的处理见[房间状态与完成](#房间状态与完成)。

## 操作计时

第一版所有禁选位置均不限时，不设置操作倒计时。流程等待当前方手动确认，提交成功后按既定流程推进。

## 主动暂停

BP 进行中，房主可以主动暂停。暂停期间，双方均不能新建、更换或清空预选，也不能提交禁选操作；暂停本身保留已有预选。由房主手动恢复 BP 后，当前操作方才能继续预选和提交。房主的撤回、换人及重开仍按各自规则处理。

## 撤回操作

1. 选手提交后不能自行修改，由房主执行撤回。
2. 房主每次只能撤回最近一个已确认操作，允许连续逐步回退。
3. 撤回后恢复该代理人的可用状态，回到对应操作位，由该位置的操作方重新选择。
4. 在「已完成」状态撤回时，返回对应操作位并暂停，由房主恢复 BP。

例如，最近提交的操作为 `BP2` 时，撤回会使流程回到 `BP2`，已完成的 `BP1` 及更早的操作保留。

## 掉线与暂停

成员在线状态按[多页面操作](room-roles.md#多页面操作)中的规则判定。

1. BP 进行中，检测到任意一方选手或房主掉线后，立即暂停整场 BP。房主是否兼任选手不影响该规则。暂停期间的预选与提交限制沿用[主动暂停](#主动暂停)中的规则。
2. 房主可以手动取消暂停，让 BP 继续。继续时仍按既定顺序处理当前操作位。
3. 掉线方可以由原选手重连，也可以换人接续当前 BP，保留已确认的禁选结果。

取消暂停后，如果当前操作方仍处于掉线状态，需要该方重连或完成换人后才能提交。

### 房主重连

房主掉线后保留其房主身份，等待重连；重连成功后，由房主手动恢复 BP。

第一版不自动转移房主权限。如果无法恢复原房主身份，需要重新建房，并从头进行本局 BP。

## 重连与换人

### 等待原选手重连

身份恢复遵循[入房身份](room-roles.md#入房身份)规则。掉线后可以保留原席位，等待原选手重连。身份仍有效且席位尚未被替换时，重连成功后原选手恢复该方的操作权。

原身份无法恢复时，再次进入按新成员以观众身份加入。原身份仍有效但席位已被替换时，按当前角色恢复，不自动取回原席位：普通成员为观众，房主仍保留其房主权限。重新取得席位须由房主按当前状态下的分配或换人规则处理。

### 房主换人

1. 普通替补先以观众身份进入房间。
2. 房主在 BP 暂停期间，从在线观众中指定接替某一方的选手；房主未占选手席位时，也可以使用自己的房主身份将自己换上场。
3. 新选手接管该方席位，继承该方全部已确认的禁选结果；原选手立即失去席位操作权。普通成员转为观众；原选手为房主时，继续保留[房主权限](room-roles.md#房主兼任选手)。

A/B 席位固定，每方始终只有一名选手拥有操作权。换人只更换席位操作者，原选手之后重连也不会自动取回席位。

房主兼任选手时，席位变更与房主权限的关系见[房间角色：房主兼任选手](room-roles.md#房主兼任选手)。

### 恢复 BP

重连和换人均不自动解除暂停，由房主手动取消暂停后继续 BP。

## 重开本局

1. 仅房主可以发起重开，弹窗确认后清空本局全部禁选结果及未提交的预选。
2. 重开后保留房间、成员、当前 A/B 席位与[队伍名](room-roles.md#队伍名管理)，回到待开始状态。
3. 满足[开局条件](room-roles.md#入房与开局)后，由房主重新开始 BP，从 `AB1` 起按既定顺序进行。

## 房间状态与完成

房间采用「待开始」「进行中」「已暂停」「已完成」四种状态。

`AP9` 提交成功后直接进入「已完成」状态。

进入「已完成」状态后，房主仍可以执行[撤回操作](#撤回操作)或[重开本局](#重开本局)。
